# Privacy Policy for Scroll Arrows

Last updated: November 23, 2026

Scroll Arrows does not collect, transmit, sell, or share any personal data.

## What the extension stores
The extension saves your display settings (opacity, size, length, speed, position, visibility, scroll mode, accent color, and effect options) using Chrome's built-in `chrome.storage.sync` feature. This data stays inside your browser and syncs only through your own Chrome account, if you have Chrome sync turned on. The developer cannot access it.

## What the extension reads
The extension runs on web pages so it can display the scroll bar and move the page when you use it. It does not read, record, or send page content, form data, browsing history, or any other information.

## Network access
The extension makes no network requests and contains no analytics, advertising, or tracking code.

## Changes
If this policy changes, the updated version will be posted at the same location with a new "Last updated" date.

## Contact
For questions, contact the developer through the Chrome Web Store listing.
